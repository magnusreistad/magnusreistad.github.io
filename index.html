ClearFlag

A fraud rules engine with explainable, agent-written rationales.

ClearFlag scores transactions against fraud rules and shows analysts exactly which rules fired. Its Investigation Agent, built on LangGraph, gathers evidence through three tools before writing a rationale an analyst can defend.

  • Deterministic tool dispatch, so every investigation follows a repeatable, testable path.
  • Append-only rationale table that doubles as a cache and an audit record.
  • Graceful fallback to a template formatter if the agent or a guardrail fails.
